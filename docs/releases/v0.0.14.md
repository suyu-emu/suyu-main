# suyu v0.0.14

This release fixes startup and export-related crashes and adds a Linux AppImage.

## Fixes

- Fixed a startup crash caused by motion callbacks running before initialization finished.
- Fixed a crash when closing suyu after a Source export or while the game list was loading.
- Fixed Source exports for game titles containing spaces, Unicode, or special characters.
- Corrected the version displayed by release builds.

**Re-export existing Static and Hybrid packages.** Updating suyu alone does not
update the emulator embedded in those packages.

## Linux AppImage

The new `suyu-linux-x86_64.AppImage` supports Ubuntu 24.04 x86-64. The existing
Linux tarball remains available.

```sh
chmod +x suyu-linux-x86_64.AppImage
./suyu-linux-x86_64.AppImage
```

To use the command frontend:

```sh
./suyu-linux-x86_64.AppImage --suyu-cmd --help
```

Without FUSE, extract and launch it:

```sh
./suyu-linux-x86_64.AppImage --appimage-extract
./squashfs-root/AppRun
```

Corresponding sources are provided in `suyu-v0.0.14-appimage-sources.tar.gz`.
Licenses and notices are included in the AppImage. The project and dependency
source archives are also available with the release.

## Testing

All platform builds and final package checks passed. The AppImage also passed
extraction, command-help, and offscreen GUI startup checks.

Windows Static playtests confirmed rendering, input response, clean exits, and
zero JIT fallback in these opening gameplay areas:

| Game | Version | Tested area | Average gameplay FPS |
| --- | --- | --- | --- |
| Mario Kart 8 Deluxe | 4.0.0 | Mario Kart Stadium opening race | 60.00 |
| Super Mario Odyssey | 1.3.0 | Cap Kingdom: running, jumping, and landing | 59.46 |
| Tears of the Kingdom | 1.4.3 | Beneath Hyrule Castle cave | 29.90 |
| Xenoblade Chronicles 3 | 1.0.0 | Opening combat and Everblight Plain | 29.72 |

These checks cover the listed opening areas, not full playthroughs or performance
comparisons. FPS averages are sampled gameplay results; startup and loading are
excluded, and shader compilation can still cause stutters.
