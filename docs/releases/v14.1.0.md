# suyu v14.1.0

This minor update fixes two graphics compatibility problems while retaining the
safer defaults introduced in v14.0.1.

## Graphics corrections

- Fixed corrupted NVIDIA rendering with graphics pipeline libraries enabled.
  Fragment-output libraries now retain the full pipeline state when cached.
- Fixed stretched character geometry in Tears of the Kingdom on macOS MoltenVK.
  Packed vertex weights use a supported three-component format when the unused
  fourth component would cross the vertex stride.

Graphics pipeline libraries, Fast GPU Time, async shader building and SPIR-V
optimization remain off by default. Explicit user settings are preserved.

**Re-export existing Static and Hybrid packages** to receive the corrected host.
Translated game code remains part of those exports; official downloads contain
no games, keys or firmware.

## Tested scope

MK8D 4.0.0 and TOTK 1.4.3 native Static opening replays completed on Linux
RTX 3090 (NVIDIA 580.159.03), Windows Radeon RX 9070 XT and macOS Apple M5.
The 6,001-frame MK8D and 12,001-frame TOTK checks used default settings and
optional pipeline-library/Fast GPU settings. All Static cases exited normally
with zero JIT transitions and zero unresolved imports; inspected gameplay
captures showed coherent geometry, textures and HUDs.

Linux RTX 3090 checks verified the NVIDIA correction; Windows Radeon checks
covered the same change as a regression test. The later Mac tests also verified
the MoltenVK correction, including an ordinary JIT TOTK replay.
The final Mac-only change also passed the Windows CLI/export-kit build.
MoltenVK on the tested Mac lacks pipeline-library support and uses the normal
fallback when that option is requested.

Later Mac MK8D race samples were around 60 FPS. Mac TOTK cave samples were around
16 FPS by default and 9–10 FPS with Fast GPU Time set to Medium. These are
functional observations, not controlled benchmarks or speedup claims.
Full playthroughs and other GPUs/drivers remain outside these checks.
