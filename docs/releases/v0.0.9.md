# suyu v0.0.9

This checkpoint improves static execution through title screens, controller prompts and menus, with attract sequences rendering in the tested configuration. Static execution remains experimental and slower during some loading and transition sequences. **Use Hybrid for the best performance.**

The CPU choices are:

- **Suyu Static (Experimental):** ahead-of-time compiled code with JIT fallback refused. The separate `no-jit` downloads are built with `SUYU_NO_JIT=ON`; Dynarmic is absent from those binaries. Missing static coverage stops execution.
- **Dynarmic JIT (Baseline):** dynamic compilation for comparison and compatibility.
- **Hybrid:** static code with Dynarmic fallback, recommended for normal use and performance.

ABI 4 uses a bounded, nonrecursive loop within each compiled module to reduce returns to the host dispatcher while retaining execution limits. Automatic per-title bundles are guarded against incompatible or stale generated code. This release uses **ABI 4**: regenerate older static bundles before using them with these binaries.

TAS recording and replay can start from boot, keeping the input origin consistent. Keep separate baseline and static replay fixtures when loading progress differs, and allow idle time after the final command when observing a transition. Input exhaustion alone does not prove that the expected screen or gameplay state was reached.

Validation covers title/menu progress, attract rendering and the race starting grid in the tested configuration. The grid was reached during bounded idle observation after the input replay ended, with no JIT available and zero fallback attempts. Race entry is delayed relative to the JIT baseline; exact EOF image parity and full-race replay validation remain open. This release does not establish universal title compatibility or frame-exact parity. No new performance benchmark is claimed.

The standard Linux and Windows downloads support Dynarmic, Hybrid and static execution. Selecting the static export mode in a standard download disables fallback in its compiled launcher but does not remove Dynarmic from an ordinary host build. Only the separate `no-jit` downloads guarantee its absence; they require a locally exported **ABI 4** static bundle. Each no-JIT package includes an audit record from checks of build inputs and executable symbols or link maps.

`suyu-v0.0.9-source.tar.gz` contains the tracked source used for these builds, including submodules. GitHub's automatic source archives omit submodule contents. No games, generated game code, keys or firmware are included or acquired by the release workflow.
