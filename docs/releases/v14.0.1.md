# suyu v14.0.1

This update supersedes v0.0.14 with safer graphics defaults and complete graphics
settings in the launcher. Releases now use major.minor.patch numbering.

## Graphics fixes

- Graphics pipeline libraries are now off by default and remain available as an experimental option.
- Fast GPU Time is now off by default. Its checkbox now actually controls GPU timing.
- Graphics → Advanced now exposes the previously hidden graphics hacks and Vulkan extension options.
- Added descriptive labels and complete choices for dynamic state, sample shading, GPU timing, and texture unswizzling.
- The Advanced page scrolls on smaller windows. Settings can be saved globally or overridden per game.

Async shader building and SPIR-V optimization remain off by default. Normal disk
and driver shader caches remain enabled. Explicit user opt-ins are preserved;
profiles using the application defaults adopt the new defaults.

**Re-export existing Static and Hybrid packages** to receive the corrected
embedded host. Updating the launcher alone does not update those packages.

## Downloads

Windows, macOS, Android, Linux tarball, and Linux AppImage downloads are provided,
along with libretro cores and corresponding sources. The AppImage targets Ubuntu
24.04 x86-64.

```sh
chmod +x suyu-linux-x86_64.AppImage
./suyu-linux-x86_64.AppImage
```

Without FUSE:

```sh
./suyu-linux-x86_64.AppImage --appimage-extract
./squashfs-root/AppRun
```

## Testing

Native tests verify the actual Qt controls, INI save/reload, per-game overrides,
and restoration of global settings. GPU timing tests verify that disabling Fast
GPU Time preserves normal ticks while explicit opt-ins retain their existing
behavior.

These changes do not establish the cause of every reported graphics issue;
compatibility can still depend on the game and GPU driver.
